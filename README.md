## 🎫 سیستم تیکت StarProject (پشتیبانی)

ما علاوه بر بازی‌ها، یک **نرم‌افزار دسکتاپ پشتیبانی** هم ساختیم تا کاربران بتوانند به راحتی مشکلات یا درخواست‌های خود را ثبت کنند.

### ویژگی‌های برنامه:
- 🔐 **ثبت‌نام و ورود امن:** (متصل به دیتابیس ابری Supabase)
- 🎫 **ارسال تیکت:** مستقیماً به گیت‌هاب (Issues)
- 📋 **تاریخچه:** مشاهده پاسخ‌های ادمین
- 👑 **امکانات VIP:** تم‌های اختصاصی و پشتیبانی اولویت‌دار
