## 📖 درباره پروژه

این ریپازیتوری شامل نسخه دسکتاپ **سیستم تیکت StarProject** است. 
هدف از ساخت این برنامه، ایجاد یک پل ارتباطی ساده و سریع بین کاربران و تیم پشتیبانی است. 

ما این برنامه را با **پایتون (Python)** و کتابخانه **CustomTkinter** توسعه داده‌ایم تا کاربران بتوانند به راحتی مشکلات یا درخواست‌های خود را ثبت کنند و تیم پشتیبانی (ادمین) به آن‌ها پاسخ دهد.
