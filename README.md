## 🎫 سیستم تیکت StarProject

علاوه بر بازی‌ها، یک نرم‌افزار دسکتاپ پشتیبانی هم ساختیم تا کاربران بتوانند مشکلات خود را ثبت کنند.

- ثبت‌نام و ورود امن
- ارسال تیکت مستقیم به گیت‌هاب
- مشاهده تاریخچه و پاسخ‌ها
- امکانات VIP (تم اختصاصی و پشتیبانی اولویت‌دار)
